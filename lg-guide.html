نصب روی تلویزیون LG

نصب «مای موویز پلاس» روی webOS از کامپیوتر ویندوز یا مک. یک‌بار تلویزیون را آماده کن، بعد اسکریپت بقیه‌ی کار را انجام می‌دهد.

فایل نصب: moviz-webos.ipkنسخه ۱.۹.۸۴

دو مرحله دارد: گام ۱ روی تلویزیون (فقط یک‌بار) و گام ۲ روی کامپیوتر. تلویزیون و کامپیوتر باید روی یک شبکه‌ی WiFi/LAN باشند.
آنچه لازم داری

پیش‌نیازها

  1. حساب رایگان LG Developer

    در developer.lge.com روی Sign In ← Create Account بزن و ثبت‌نام کن (با گوشی یا کامپیوتر). ایمیلت را تأیید کن. این حساب برای روشن‌کردن Developer Mode لازم است.

  2. یک کامپیوتر ویندوز یا مک

    به اینترنت وصل باشد (بار اول ابزارهای لازم خودکار دانلود می‌شوند) و روی همان شبکه‌ی تلویزیون باشد.

روی تلویزیون — فقط یک‌بار

گام ۱ — نصب و فعال‌کردن Developer Mode

  1. نصب اپ Developer Mode

    دکمه‌ی Home ریموت را بزن، LG Content Store (یا Apps) را باز کن، عبارت Developer Mode را جست‌وجو کن و اپ را نصب کن.

  2. ورود به حساب

    اپ Developer Mode را باز کن و با ایمیل و رمز حساب LG Developer که ساختی وارد شو.

  3. روشن‌کردن Dev Mode Status

    کلید Dev Mode Status را ON کن. تلویزیون می‌پرسد ری‌استارت شود — تأیید کن. صبر کن تا دوباره روشن شود.

  4. روشن‌کردن Key Server

    بعد از ری‌استارت، دوباره اپ Developer Mode را باز کن و کلید Key Server را ON کن. اسکریپت از این طریق کلید اتصال را از تلویزیون می‌گیرد.

  5. یادداشت IP و Passphrase

    در همان صفحه دو مقدار را یادداشت کن: IP (مثل 10.0.0.55) و Passphrase (کد ۶ حرفی مثل AB12CD). در گام ۲ لازمشان داری.

روی کامپیوتر

گام ۲ — نصب خودکار با اسکریپت

⬇ دانلود پکیج نصب (اپ + اسکریپت) moviz-lg-installer.zip

  1. باز کردن zip

    فایل اپ و اسکریپت‌ها همه داخل همین پکیج‌اند. کل فایل را در یک پوشه از حالت فشرده خارج کن (ویندوز: راست‌کلیک ← Extract All؛ مک: دوبار کلیک).

  2. اجرای اسکریپت

    ویندوز: روی install-lg.bat دوبار کلیک کن. اگر پیغام «Windows protected your PC» آمد، More info ← Run anyway را بزن.

    مک: روی install-lg.command راست‌کلیک ← Open و دوباره Open را بزن (فقط بار اول؛ دفعه‌های بعد دوبار کلیک کافی است).

  3. وارد کردن IP و Passphrase

    اسکریپت ابزارهای لازم را خودش دانلود و نصب می‌کند، بعد IP و Passphrase تلویزیون را می‌پرسد. بعد از اتصال، اپ نصب و روی تلویزیون باز می‌شود. ✅

اگر به مشکل خوردی

عیب‌یابی

+ TV not reachable

کامپیوتر به تلویزیون دسترسی ندارد. بررسی کن هر دو روی یک شبکه‌اند، IP را درست وارد کرده‌ای و Dev Mode Status روشن است. IP ممکن است بعد از خاموش‌وروشن‌شدن مودم عوض شود — از اپ Developer Mode دوباره نگاه کن.

+ Key Server looks OFF

در اپ Developer Mode کلید Key Server را روشن کن و در اسکریپت Enter بزن.

+ Connection failed / passphrase اشتباه

Passphrase را دقیقاً مثل اپ وارد کن (حروف بزرگ). اگر باز هم خطا داد، اپ Developer Mode را ببند و دوباره باز کن تا مقدار تازه را ببینی.

+ اپ Developer Mode در Content Store پیدا نمی‌شود

کشور/منطقه‌ی تلویزیون در تنظیمات ممکن است این اپ را نشان ندهد. در Settings ← General ← Location کشور را عوض کن و دوباره جست‌وجو کن.

+ اپ بعد از چند روز از تلویزیون پاک شد

زمان Remain Session تمام شده. در اپ Developer Mode دکمه‌ی Extend را بزن و دوباره اسکریپت را اجرا کن.

+ اپ باز می‌شود ولی می‌گوید «اتصال اینترنت برقرار نیست»

با اینکه اینترنت تلویزیون وصل است، یعنی webOS جلوی درخواست‌های cross-origin مای‌موویز را با CORS گرفته. اگر این را دیدی بگو تا یک راه‌حل (پراکسی سبک) اضافه کنم.

+ فیلم پخش نمی‌شود

روی webOS پخش با <video> مرورگر است؛ اگر عنوانی پخش نشد، لینک/فرمت آن را بگو تا بررسی کنم.
