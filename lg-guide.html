نصب روی تلویزیون LG

نصب «مای موویز پلاس» روی webOS از یک کامپیوتر ویندوز — بدون ترمینال، فقط با یک برنامه‌ی گرافیکی.

فایل نصب: moviz-webos.ipkنسخه ۱.۹.۴
i
یک‌بار روی تلویزیون باید Developer Mode روشن شود (گام ۱). تلویزیون و کامپیوتر باید روی یک شبکه‌ی WiFi/LAN باشند.
آنچه لازم داری

پیش‌نیازها

  1. فایل نصب اپ

    فایل moviz-webos.ipk را از صفحه‌ی دانلود بگیر (دکمه‌ی «دانلود بسته‌ی webOS»).

  2. برنامه‌ی Dev Manager Desktop

    یک برنامه‌ی گرافیکی رایگان برای ویندوز. نسخه‌ی ویندوز (.exe) را از اینجا بگیر: github.com/webosbrew/dev-manager-desktop

  3. حساب رایگان LG

    برای روشن‌کردن Developer Mode روی تلویزیون لازم است: در developer.lge.com ثبت‌نام کن.

روی تلویزیون — یک‌بار

گام ۱ — روشن‌کردن Developer Mode

  1. نصب اپ Developer Mode

    در LG Content Store اپ «Developer Mode» را نصب کن، بازش کن و با حساب developer.lge.com لاگین کن.

  2. فعال‌سازی

    Dev Mode Status را ON کن؛ تلویزیون یک‌بار ری‌استارت می‌شود.

  3. یادداشت اطلاعات

    دوباره اپ Developer Mode را باز کن و بردار: IP تلویزیون (مثل 10.0.0.55) و Passphrase (کد ۶ حرفی مثل AB12CD). گزینه‌ی Key Server روشن بماند.

روی ویندوز

گام ۲ — نصب با Dev Manager Desktop

  1. برنامه را باز کن

    فایل .exe که دانلود کردی را روی ویندوز نصب و اجرا کن.

  2. تلویزیون را اضافه کن

    روی دکمه‌ی + (Add Device) بزن و IP و Passphrase تلویزیون را وارد کن تا وصل شود.

  3. نصب فایل ipk

    به بخش Apps برو، دکمه‌ی Install را بزن و فایل moviz-webos.ipk را انتخاب کن. چند لحظه بعد، اپ در ردیف برنامه‌های تلویزیون ظاهر می‌شود. ✅

✔
برای به‌روزرسانی در آینده، همین کار را با فایل .ipk جدید تکرار کن؛ داده‌ها و تنظیمات روی تلویزیون حفظ می‌شود.
اگر به مشکل خوردی

عیب‌یابی

+ Dev Manager به تلویزیون وصل نمی‌شود

تلویزیون و کامپیوتر روی یک شبکه‌اند و IP درست است؟ Developer Mode روشن و Key Server فعال است؟

+ خطای کلید / passphrase نامعتبر

کلید دسترسی هر چند وقت منقضی می‌شود. در اپ Developer Mode یک passphrase تازه بگیر و دوباره در Dev Manager وارد کن.

+ اپ باز می‌شود ولی می‌گوید «اتصال اینترنت برقرار نیست»

با اینکه اینترنت تلویزیون وصل است، یعنی webOS جلوی درخواست‌های cross-origin مای‌موویز را با CORS گرفته. اگر این را دیدی بگو تا یک راه‌حل (پراکسی سبک) اضافه کنم.

+ فیلم پخش نمی‌شود

روی webOS پخش با <video> مرورگر است؛ اگر عنوانی پخش نشد، لینک/فرمت آن را بگو تا بررسی کنم.

ناوبری با ریموت جهت‌دار مثل نسخه‌ی اندروید کار می‌کند.
Dev Manager Desktop نسخه‌ی مک و لینوکس هم دارد؛ مراحل یکسان است.
